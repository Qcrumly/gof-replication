# GOF Specification

The working specification document (v3.2.0) is maintained outside this repository alongside the paper drafts.

For the current mathematical results, see the paper:

**Graves Octonionic Framework (GOF): Journeys, Anchor-Local Reduction, Parity-Sign Identity, and an Exact Reduction Law**
by Quintin Crumly

Key results:
- **Parity-Sign Identity**: For any chain with a terminal collapse, the terminal value is (−1)^{℘(J)}. Both parities occur.
- **Exact Reduction Law**: P(reducible) = 1 − (6/7)^{L−2}, derived from the collapse rate 1/7.
- **Markov Stationary Law**: P(scalar-valued) → 1/8.
- **Association Fidelity**: W(𝕆) = 11/32.

The verification scripts in `verification/` independently confirm these results.
