# Artifacts

## H14 Percolation Operator (Historical)

The files `H14_fsa_config.json` and `H14_fsa_report.json` document the percolation operator F(S) = 1 − exp(−(aS + bS²)) and its matrix-free stationary certificate.

**Note:** The percolation operator has been superseded by the exact reduction law P(reducible) = 1 − (6/7)^{L−2}, which matches exhaustive enumeration to all decimal places and requires no fitted parameters. See §5 of the paper.

These files are retained for historical completeness and because some CI workflows still reference them.
